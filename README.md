# HARETC-Smart-Grid-CPS

## Overview

This repository contains the MATLAB implementation and synthetic experimental dataset associated with the HARETC (Hierarchical Adaptive Resilient Event-Triggered Control) framework for cyber-physical smart grid applications.

The framework integrates adaptive event-triggered communication, edge-assisted attack estimation and state reconstruction, and adaptive resilient control for smart grid systems under hybrid cyber attacks.

## Framework Components

- Adaptive Event-Triggered Communication
- Hybrid Cyber Attack Modeling
- Edge-Assisted Attack Estimation
- State Reconstruction
- Adaptive Resilient Control
- Self-Adaptive Gain Update
- Cloud-Assisted Coordination

## Cyber Attacks

The framework considers the following attack scenarios:

- Denial-of-Service (DoS)
- False Data Injection Attack (FDIA)
- Bias Attack
- Burst Attack
- Hybrid Cyber Attack

## Dataset

The experiments use PMU measurement data as the underlying smart-grid data source. Synthetic cyber-attack and simulation data are generated programmatically for evaluating the HARETC framework.

The repository includes:

- `HARETC_Synthetic_Dataset.xlsx`
- `HARETC_Synthetic_Dataset.txt`
